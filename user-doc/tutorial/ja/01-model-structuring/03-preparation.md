# 03. 準備

最初に、次の状態にしておきます。

- キャラクターの画像素材（頭・胴・腕・脚・髪・衣装など）が、ある程度 Part として読み込まれている
- エディタ上で、ツリー（Node / Part の一覧）が見える状態になっている

まだ画像を読み込んでいない場合は、先に ファイル → インポート（PSDファイルをインポート...、KRAファイルをインポート...、画像フォルダをインポート...）で読み込んでおきます。Part は読み込んだ画像から作られます。「ノード」パネルで作れるのは Node、Composite、DynamicComposite、GridDeformer などの補助ノードで、Part は作れません。
