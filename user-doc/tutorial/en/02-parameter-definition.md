# Parameter Definition Tutorial (Basic Parameters / Deformation Setup)

This tutorial covers which parameters to create after you structure the model, and how to assign them to each Part and Deformer.

This chapter focuses on the basic parameters to create first: face, body, eyes, eyebrows, and mouth. For physics, such as hair and clothing sway, it covers only the basic approach and entry points. Detailed tuning is left to another chapter.
