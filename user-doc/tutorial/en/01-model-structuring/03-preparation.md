# 03. Preparation

First, get into the following state:

- The character's image assets (head, torso, arms, legs, hair, clothing, and so on) are loaded as Parts to some extent.
- The tree (the list of Nodes and Parts) is visible in the editor.

If you have not loaded your images yet, import them first with File → Import (Import PSD..., Import KRA..., or Import Image Folder...). Parts come from imported images; the Nodes panel creates Node, Composite, DynamicComposite, GridDeformer and other helper nodes, but it cannot create a Part.
