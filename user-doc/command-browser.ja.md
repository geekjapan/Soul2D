# コマンドブラウザー

**Edit > Command Browser** を開くと、エディタの操作や MCP ツールをエディタ内から実行できます。

## コマンドを実行する

1. ラベル、カテゴリ、または `new file` などの英語で検索します。
2. 一覧から行を選びます。エディタの操作と MCP ツールが同じ一覧に表示されます。
3. ツールの場合は、**Arguments** に JSON オブジェクトを入力します。必須項目はパネルに表示されます。
4. **Run Command** を選びます。無効なコマンドは実行されず、ブラウザーも閉じません。

エディタの操作を開始すると、操作が拒否された場合も通常はブラウザーが閉じます。
エディタのステータスメッセージを確認してください。ブラウザーを開く 2 つの操作では、現在の入力を維持します。
ツールの実行では通常は開いたままとなり、**Result** に結果が表示されます。閉じると検索、入力、結果が消去されます。

## 文書や選択が変わった場合

開始を待っているコマンドは、別の操作で文書が置き換わるか、保存先のパスが変わると拒否されます。
パスを変更して元に戻した場合も、予約済みのコマンドは無効になります。ノード操作では選択ノードと
クリップボードを、タイムライン操作では選択クリップ、実際の再生位置、キーに記録する値を再確認します。古くなったコマンドは
ブラウザーを閉じません。現在の文書とコマンドを確認してから、再度実行してください。

**Save** は、ツールバーに別の文字列が入力されていても、文書の実際の保存先を使います。未保存の文書では
Save As ダイアログを開きます。**Open** と **Save As** はダイアログを開くだけで、ダイアログを完了するまで
ファイルを開いたり保存したりしません。**New** は、既存の未保存変更の設定と Save/Don't Save/Cancel ダイアログに従います。

## 結果を確認する

結果が不明な場合も、コマンドに効果がなかったとは限りません。再実行する前に文書を確認してください。
長い結果は短縮される場合があります。バックグラウンド書き出しの開始は、処理が始まったことを示すため、完了はステータスで確認してください。

MCP での表示切替と状態の読み取りは、[MCP API](../doc/mcp_api.md)（英語）に記載されています。
