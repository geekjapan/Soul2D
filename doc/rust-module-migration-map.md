# Rust migration removal map

Status: **D removal complete: no D source remains.** The per-module table is not exhaustive (see the last bullet). `python3 tools/d-to-rust-inventory.py`
reports `dFileCount: 0`; the product is the Rust crate in `rust/`. Paths in the
first column of the tables are relative to `source/soul2d/` unless they start
with `source/` or `tools/`; Rust paths are relative to `rust/src/`. Existing Rust
modules are replacement seams, not parity claims: the "Not ported" cells and the
known gaps below record where behaviour differs.

- Autosave directories are keyed by file stem plus a checksum of the resolved project path, with an owner file that settles checksum collisions (D used the stem alone, so same-name projects collided). On Unix a project moved or renamed on the same filesystem takes its backup directory along: the directory records the file's device, inode, length and modification time, and is adopted when the same file turns up under a new path. A copy, a move across filesystems, a file changed by another program, Windows hosts and the stem-only directories of earlier builds are not followed.
