# Soul2D project artwork

All images under `res/`, `build-aux/osx/soul2d.iconset/`,
`build-aux/osx/dmgbg.png`, `build-aux/windows/soul2d.ico`, and the
WiX bitmaps under `build-aux/windows/wix/res/` are generated by
`tools/generate-project-artwork.py` using only the Python standard
library.

The artwork is self-authored parametric geometry: two offset
quadrilateral planes joined by circular control points in a dark-ink,
warm-cream, vermilion, and cyan palette. It contains no character or
mascot artwork, no inherited wordmarks, and no downloaded fonts; the
SOUL2D wordmark uses a small bitmap glyph set defined in the generator.
No prior project artwork files were traced, sampled, or reused, so these
assets do not carry over any rights restrictions of the images they
replace.

## Regeneration

    python3 tools/generate-project-artwork.py            # verify on-disk bytes
    python3 tools/generate-project-artwork.py --write    # write all assets
    python3 tools/generate-project-artwork.py --selftest # corruption-detection test

`res/project-artwork.json` lists every generated file with its format,
dimensions, and SHA-256 for review and integrity checking.
